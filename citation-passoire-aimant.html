Rappel — པ་ · པོ་ · བོ་ : un seul nominalisateur, trois formes ; ངན་པ་ « le mauvais », བཟང་པོ་ « le bon », སྐྱེ་བོ་ « celui qui est né, la personne ».
Wylie
bzang po shor nas ngan pa ’dzin / skye bo ngan pa chu tshag ’dra / ngan pa spangs nas bzang po sgrub / khab len rdo dang ya rabs mtshungs //
Prononciation
sang-po shor né · ngèn-pa dzin ‖ kyé-wo ngèn-pa · tchou-tsak dra ‖ ngèn-pa pang né · sang-po droup ‖ khap-len do dang · ya-rap tsoung
Traduction littérale
« Ayant laissé échapper le bon, il retient le mauvais : l’homme de peu est semblable à une passoire.
Ayant rejeté le mauvais, il accomplit le bon : à la pierre d’aimant, l’homme de bien est pareil. »
Traduction retenue
« Laisser fuir le bon, retenir le mauvais —
l’homme vil est une passoire ;
rejeter le mauvais, accomplir le bon —
l’homme de bien, une pierre d’aimant. »
Tous reçoivent la même matière ; seul diffère ce qu’ils en gardent.
